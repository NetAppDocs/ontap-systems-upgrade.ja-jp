= 必要な工具とドキュメント
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
新しいハードウェアを設置するための特別なツールが必要です。また、アップグレードプロセス中に他のドキュメントを参照する必要があります。

アップグレードを実行するには、次の工具が必要です。

* アースストラップ
* No.2 プラスドライバ
